# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-06-10
### Added
- Initial release of `remo-cli`.
- `remo init` interactive wizard to create `.remo` configs.
- `remo` startup panel with rich UI display.
- `remo remind` for detached cross-platform desktop notifications.
- Auto-reminders triggered on project startup.
- `remo check` environment validation (env, version, file, cmd).
- `remo log` for micro-logging project tasks.
- `remo run` for executing project shortcuts defined in `.remo`.
- `remo snooze` to snooze the most recent reminder.
- `remo status` to view current session elapsed time and reminders.
- `.remo.local` support for personal config overrides.
